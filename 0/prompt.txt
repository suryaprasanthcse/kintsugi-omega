**Stage 6 amendments (full)**

- **A-47 — held hits.** A hit below its paging threshold is `held` against `WATCH-<receptor>-<host>`, which counts as a dedupe record for I7/C9. Held hits are attached to the incident when the threshold is reached. Stage 4 stores migrate in place.
- **A-48 — G3 command.** G3 runs `entire graph verify` with `pytest -rA`. The plugin always exits 0, so the `NEWLY FAILING (n)` verdict is parsed. With `-q` it degrades to an exit-code-only verdict. G7 computes the same delta from two `pytest -rA` runs.
- **A-49 — L4.** A winner chosen while main moved is re-verified merged onto the new main in a scratch worktree; it is never rebased.
  - G1 and G2 always re-run; G3 only for tests in the impact radius; G4 only when the graph radii intersect, otherwise reused with the reason recorded.
  - This sits behind `workflow.patched("l4-reverify-winner")`. A failed re-check or a merge conflict fails the round.
- **A-50 — `.kintsugi/target.yaml`.** It declares each target host, including `live_services`: services holding the host's own state are never recorded in or replayed from cassettes.
- **A-51 — merges.** Merges keep the attested commit, so PRs merge with a merge commit (no linear-history rule). Ruleset conditions list branches explicitly, each added right after creation, because a required status check also blocks the push that creates a matching branch.
- **A-52 — delivery framing.** A delivery prompt must not promise behaviour its patch contradicts. Haiku 5.5 refused the practice patch under "keep behavior identical" and applied it under the spec's §6.2 framing. Stage 8's Saboteur must plan for a model that reviews the patch.

- **A-55 — decision rule.**
  - A G5 `concern` makes a hypothesis a last-round fallback only.
  - Pareto dominance ignores noise (2 points of pass rate, 2% cost, 5% p95), so equivalent fixes go to a pre-registered experiment.
  - The experiment's protocol hash is checked before it runs; its criterion is pass rate, then mean cost, then diff size.
  - G4 runs base and candidate back to back per seed, with no cross-audit cache.
