## 4. Architecture and APIs Stage 6 builds on

### 4.1 `kintsugi/control/` (Stage 5)

**The Crew port is Stage 6's main integration point.** `activities.Crew.handle(ctx: StepContext, *args) -> Any` dispatches on `ctx.name`. `StepContext(name, key, attempt, heartbeat)`. Long steps run in a thread and are heartbeated automatically. Raise `InvalidAlert`, `BudgetExceeded` or `ProtectedPathViolation` for non-retryable failures. Workers load the crew with `python -m kintsugi.control.worker --target localhost:7233 --pool crew|surgeon|senses (repeatable) --crew <module:factory> [--workflows kintsugi.control.workflows:WORKFLOWS] [--ledger .state/control/steps.sqlite] [--heartbeat-interval s] [--log file]`.
