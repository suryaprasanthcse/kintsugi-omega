Given a fleet H of AI agents and an autonomy window W, keep every agent at or above its reliability SLO and the fleet at or above the gross-margin floor (GM_floor 0.70) while an adversary attacks both the agents and the immune system, with **zero human commits to protected branches**, and produce a signed, independently checkable account of every infection, repair, prevention and economic decision. Biological model: neatlogs = senses (afferent/efferent), Entire = episodic memory + body map (entire-graph) + notary, cfo.ai = metabolism; antibodies compound (Wright's law, Zipf coverage, network effect).

### 1.4 Orchestrator commit protocol (`kintsugi/proof/commit.py::orchestrator_commit`)
`git add -A` → refuse if nothing changed → refuse staged paths not explained by the session's Write/Edit tool calls (`session_paths`, from `tool_edited_paths(stream.tool_uses, worktree)`; A-16) → refuse protected-path violations → refuse diff > 120 lines unless `approved_large_diff` → `git write-tree` + parent → sign attestation → message = subject + body + `Kintsugi-Incident/Role/Nonce/Prompt/Attestation` trailers → refuse forbidden trailers → `git commit -F -` (gateway forces ENTIRE_TEST_TTY=0; Entire's hook appends `Entire-Checkpoint:`) → verify tree & parent unchanged, exactly one valid ULID checkpoint trailer, and the ref exists → otherwise `reset --soft parent` and raise `CheckpointMissing` (an unlinked commit is never kept). `Kintsugi-Prompt` = sha256 of the exact first-prompt bytes (A-17).
